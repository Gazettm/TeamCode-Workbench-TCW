# 0.2.0 开发交接

日期：2026-11-10。

F01：本机备注字号和对比度提升；16px 摘要最多两行，16px 编辑正文。0.1 原有离线数据保留。F02：真实 Spring Boot 和 MySQL 后端、注册登录退出、私有项目及成员、可过期撤销的邀请、多人加入和项目切换。

接口见 [0.2 接口契约](0.2-api.md)。主要实现为 `server/src/main`、`desktop/collaboration.cjs`、`desktop/main.cjs`、`desktop/renderer/Projects.vue`。`scripts/Start-LocalServer.ps1` 启动独立的本机 MySQL 和 API；`scripts/verify-local-api.mjs` 对指定的隔离实例运行联调。

安全边界：用户及项目权限在后端校验；用户密码、邀请码和会话令牌在数据库保存摘要；桌面令牌只存主进程内存；备注和工作区路径不上传。默认监听本机，非本机地址由客户端要求 HTTPS。
