# 0.2 账号和项目接口

服务默认监听 127.0.0.1:8080。请求与响应使用 JSON；除健康检查、注册和登录外，必须提供 Authorization: Bearer <token>。成功的删除返回 204。错误统一返回 {"code":"错误码","message":"可显示提示"}。客户端不以传入 userId 或自称角色判断权限。

| 方法与路径 | 请求 | 成功结果 |
| --- | --- | --- |
| GET /api/health | 无 | service、version、status |
| POST /api/auth/register | username、displayName、password | 201，user；需另行登录 |
| POST /api/auth/login | username、password | token、expiresAt、user |
| POST /api/auth/logout | 无 | 204，注销当前会话 |
| GET /api/me | 无 | id、username、displayName |
| GET /api/projects | 无 | 仅本人所属项目的数组 |
| POST /api/projects | name | 201，项目 id、name、role；创建者为 OWNER |
| GET /api/projects/{id} | 无 | 项目 id、name、role |
| GET /api/projects/{id}/members | 无 | 成员 id、username、displayName、role |
| GET /api/projects/{id}/invitations | 无 | 组长可查邀请码状态；不返回明文码 |
| POST /api/projects/{id}/invitations | validHours（1–168） | 201，id、expiresAt、code；明文只在创建时返回 |
| DELETE /api/projects/{id}/invitations/{invitationId} | 无 | 204，重复撤销无额外副作用 |
| POST /api/invitations/join | code | 项目 id、name、role；重复加入不改变角色 |

401：会话失效或登录失败。403：项目成员无组长权限。404：项目不存在或请求人不是成员；不区分这两种情况。409：账号名重复。400：输入不合法或邀请码无效、已撤销、已过期，三种邀请码错误统一提示。

项目成员关系只由服务端保存。邀请码是可重复使用的邀请，撤销只阻止新加入，不移除现有成员。任务、动态、成员移除属于后续版本。
