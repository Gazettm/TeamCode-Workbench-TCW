# 0.4.0 交接记录

日期 2026-11-24。该版本增加桌面 Git 操作，协作 API 和 MySQL 表沿用 0.3.0。0.4.1 在改动列表中加入中文文件状态和全选，提交按钮旁显示缺少的条件。0.4.2 更新工作区、协作项目和设置的布局。0.4.3 增加分支对齐和本地分支删除。

在 Windows 安装 Git for Windows 和 Node.js 22.12+，在仓库根目录运行以下命令。

~~~powershell
npm ci
npm run dev
~~~

`npm run pack` 将 Windows x64 免安装版输出到 release/0.4.3。发布时保留整个 TCW-win32-x64 目录。要试账号、项目和任务，另开终端执行 `.\scripts\Start-LocalServer.ps1`，再把客户端服务地址设为 http://127.0.0.1:8080。

1. 打开「本地工作区」，导入本机仓库，或输入 GitHub HTTPS/SSH 地址后选择父目录。克隆成功后自动导入。
2. 在「设置」选择该仓库，填写作者姓名和邮箱。私有仓库使用本机 Git 凭据。
3. 登录后，在「协作项目 → 成员与仓库」绑定本机仓库。在「任务」中关联已有分支，或从已确认的当前提交创建任务分支。
4. 回到「本地工作区 → Git 操作」，点击文件名查看差异、勾选文件并提交。推送前确认当前分支和远程目标。首次推送没有上游时，默认推到 origin 的同名分支。
5. 获取远程状态后可查看领先和落后数。快进更新要求干净工作区和可用上游。分叉时，如果要让当前本地分支跟远程一致，可在「更多」选择「对齐到远程分支」。客户端会获取该上游、显示二次确认并备份原提交。
6. 提交验收时，客户端会检查关联分支是否已检出，并提示仓库未提交改动或已知未推送提交。

完整运行说明、代码结构和验证记录位于工作空间的版本文档/0.4。
