# 0.3 任务接口

沿用 0.2 Bearer 会话和错误格式。所有接口均核验路径中的项目成员资格。

| 方法与路径 | 输入或结果 |
| --- | --- |
| GET /api/projects/{p}/tasks | 最近 500 个任务，含 version、overdue、roundNo |
| POST /api/projects/{p}/tasks | title、description、可空 assigneeId、可空 dueAt；仅组长 |
| POST /api/projects/{p}/tasks/{t}/{action} | version 必填；按动作传 text、memberId、dueAt |
| GET /api/projects/{p}/tasks/{t}/rounds | 本任务历轮成果、复核、最终决定 |
| GET /api/projects/{p}/activities?before={id} | 默认最新 100 条；返回唯一 ID |
| POST /api/projects/{p}/members/{u}/remove | reason 必填；仅组长，先处理未完成任务 |

action：claim、start、submit、delegate、revoke-review、review、accept、return、assign、deadline、cancel。
submit/review 须 text；return/assign/deadline/cancel 须原因 text；delegate/assign 须 memberId。deadline 的 dueAt 空值表示清除截止时间。

组长可以把当前验收轮次委派给一名当前项目组员。组长本人和任务负责人均不在候选范围。已有委派时，重复提交或直接更换会被拒绝。等待意见期间，组长可执行 revoke-review 撤回委派，随后可自行验收或重新委派。撤回也会记入项目动态。

当前受委派者可提交一次意见。等待意见期间，组长的 accept 和 return 请求会被拒绝。意见提交后，本轮意见和复核人保留在验收历史中，由组长作最终决定。退回后重新提交会开启新的验收轮次。

版本冲突 409；无权限 403；跨项目或非成员 404；非法内容、错误委派和不能移除 400。UTC 时间点用 ISO 8601。失败不会产生成功动态；提交验收与 Git 操作无自动联动。
